My antivirus blocked or removed the program

New programs are sometimes flagged by mistake.

Steps

  1. Open your antivirus program and look in Quarantine or History for ClearDesk IQ.
  2. If it is ClearDesk IQ installed from the Microsoft Store, choose Restore or Allow. If the antivirus names a specific threat, stop and email us the detection name instead.
  3. Still blocked? If the program opens, click Backup (top right) first. Then reinstall ClearDesk IQ from the Microsoft Store.

Check that it worked

The program opens normally.

Still stuck?

Still stuck after these steps? Open ClearDesk IQ in the Microsoft Store, choose Publisher support, and include the help code shown on screen (for example CSC-APP-001).
