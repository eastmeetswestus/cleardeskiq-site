Connect your office computers (host + other computers)

One main computer is the HOST. Each other computer requests to join, and the host types in its 6-digit code.

Steps

  1. Pick ONE main computer as the HOST (the office desktop that stays on). Install ClearDesk IQ there first. Every computer needs the same version and the same office Wi-Fi (not guest Wi-Fi).
  2. HOST: Company & settings → Office network → Show Office & devices. Open Office & devices → Start office sharing → Set up office network (choose Yes when Windows asks) → Check connection.
  3. OTHER computer: Company & settings → Office network → Show Office & devices. Open Office & devices → Set up office network → Yes. It must say Standalone.
  4. OTHER computer: under Nearby offices click Request to join beside your office (click Refresh nearby if it is not listed). A 6-digit code appears. Leave it open.
  5. HOST: Office & devices → Requests to join → Approve beside that computer. Type the 6-digit code, choose access (Owner / manager, Crew, or Full access) and click Approve connection.
  6. Keep both apps open while the records download. Repeat for each computer; each gets its own code.
  7. Not listed in Nearby? Host: Create device invitation → copy the long code. Other computer: I already have a connection code → paste → Connect.
  8. Only Create device invitation appears on the other computer? It was made a host by mistake: Office & devices → Stop hosting on this computer, then request to join again.

Check that it worked

The other computer shows your company name and jobs, and the host lists it under Office & devices.

Still stuck?

Still stuck after these steps? Open ClearDesk IQ in the Microsoft Store, choose Publisher support, and include the help code shown on screen (for example CSC-APP-001).
