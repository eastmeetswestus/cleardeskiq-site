Connection code rejected, used twice or device revoked

Use a long code only in I already have a connection code. Six-digit approval uses the separate nearby-pairing flow.

Steps

  1. If this screen has no place to paste a code and says Office host, use the missing Join guide first. Do not rename or delete the app data folder.
  2. Check that the complete code was copied, without extra messages or missing characters, and that the office host is reachable.
  3. Ask the office whether this exact device is listed as Active or Revoked. A revoked device cannot resume sync using its old code.
  4. Use one invitation per device. Do not reuse another employee’s connection code or clone a paired computer profile.
  5. If a code was exposed or a paired laptop is lost, revoke that device from the office. Preserve pending work on an available laptop before any administrator-led reconnection.
  6. For an already-paired client there is no general self-service disconnect/merge wizard. Do not delete its connection file to force re-pairing.

Check that it worked

A separately invited authorized device connects, or its pending work is preserved for administrator recovery.

Still stuck?

If these steps do not match your screen, check Company & settings for your version and whether you are using Demo, a field laptop or the office workspace. Search the displayed error or save a support report.
