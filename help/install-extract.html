The program will not open, or a DLL is missing

Run the Windows Setup installer, then use the Start menu shortcut.

Steps

  1. Run ClearDesk IQ Setup and finish installation.
  2. Open ClearDesk IQ from the Start menu or desktop shortcut. Do not move individual runtime files.
  3. If files are missing, reinstall the same or newer verified release without deleting your company data.
  4. Use a supported Windows x64 computer. Send the exact error and diagnostic report to support if launch still fails.

Check that it worked

The main workspace opens. The real workspace is empty on first use unless you restore your own backup.

Help codes

This article covers these on-screen help codes:

  • CSC-OPEN-001

Still stuck?

Do not download replacement DLLs from third-party sites, disable security protection, or delete company.sqlite as a troubleshooting step.
