Save a backup that can restore all your records

A JSON workspace backup can restore records; an Excel export cannot.

Steps

  1. Confirm you are in your real company, then choose Backup or Reports & exports → Save backup.
  2. Choose a filename and a safe location. Keep a current copy outside the computer as well as local recovery copies.
  3. Wait for Your file has been saved. Do not edit the contents of a backup JSON file.
  4. A workspace backup contains customer and financial records. Store it privately and do not send it for troubleshooting unless a specific need and secure method are agreed.
  5. Exporting a troubleshooting report is different: that report intentionally omits the business records.

Check that it worked

A nonempty JSON file exists at the selected location and the program reported a successful save.

Still stuck?

Search save failures if the export does not complete. Never assume automatic local copies protect against loss of the whole computer.
