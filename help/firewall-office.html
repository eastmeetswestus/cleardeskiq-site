Allow office sync without turning off Windows Firewall

Use the app’s setup button for rules limited to ClearDesk IQ and the local trusted network.

Steps

  1. Open the installed ClearDesk IQ app → Office & devices → Set up office network on each computer.
  2. Read the prompt and approve only if this is your trusted office network. Windows may request an administrator account.
  3. The helper allows this installed app’s office port and nearby-discovery port on Private or Domain networks in the local subnet. It does not turn off the firewall.
  4. If Windows says the network is Public, use the network-profile guide. Do not mark a hotel, coffee-shop or other public network as Private.
  5. If your employer or security software manages the firewall, ask that administrator to approve the specific app. The setup button cannot override their policy.
  6. Return to Office & devices → Check connection. If the host itself is not listening, follow that guide; another firewall change will not start it.

Check that it worked

The host responds and the paired laptop connects with the firewall still enabled.

Still stuck?

For a VPN or separate subnet, these local-subnet rules may be insufficient. Have your administrator allow only the intended VPN clients; do not use an unrestricted allow rule.
